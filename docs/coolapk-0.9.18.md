## 正文

**类原生补全计划** 是一个面向类原生 Android 的 LSPosed 模块，把系统里缺的、用起来别扭的几处补上：小窗、弹幕通知、快捷建议、图标适配、来电拦截、防摇一摇、边缘防误触，以及通知与控制中心的横屏和状态栏调整。

不依赖无障碍，不接管默认拨号或桌面，不要求给普通应用逐个勾选作用域。所有设置默认关闭，数据留在本机。

### 小窗

- 基于系统原生 freeform 的**真实任务小窗**，不是截图浮层，页面、输入和播放都正常。
- 屏幕角落斜向滑动呼出扇形菜单，常用应用和快捷功能都在里面；快捷功能含 Wi-Fi、免打扰、旋转锁定、静音、截屏、录屏、亮度、音量与媒体控制。
- 迷你窗双击回全屏；单击空白关闭；长按切换大小、单独静音本应用。
- 迷你窗拖到屏幕边缘会隐藏成一条白色小把手，点一下或向屏内拖动即可带回，应用继续在后台运行。
- 通知、链接、分享、文件打开可以直接落在小窗里，跨应用跳转不会退回首页重开。
- 普通小窗位置固定，不跟手乱飘；键盘弹出时自动上移，横屏靠左，避让挖孔。

### 弹幕通知

- 通知变成一行从右向左滚动的弹幕：应用图标 + 来源 + 正文，不挡操作、不打断当前页面。
- 每个应用单独开关；锁屏、键盘、系统面板、小窗菜单出现时自动暂停，恢复后从原位置继续。
- 保留最近 100 条弹幕记录，可随时清空。
- 属于“显示后取消原通知”，不拦截通知到达，提示音和震动仍由系统正常发出。

### 快捷建议

- 手电筒、本次常亮、蓝牙连接、验证码、链接口令、地址地点，按场景浮出圆形按钮。
- 验证码可直接逐位填入当前输入框，默认 100ms 一位，保留前导零；隐藏验证码通知为独立开关。
- 链接覆盖淘宝、京东、拼多多、抖音、快手、B 站、小红书、知乎、微博、美团；纯口令只打开应用，不假装直达商品。
- 按钮可调大小、显示时长和位置，长按拖到底部 X 即可隐藏本次提示。
- 系统悬浮旋转按钮可替换成简洁的双箭头按钮，方向、点击、撤销和超时仍由系统原生逻辑决定。

### 图标适配

- 导入本地 ZIP 或文件夹形式的图标包，支持 `icons/<包名>/0.png` 背景与 `1.png` 前景，也支持主题目录和 MTZ 里的内层图标包。
- 逐应用选择彩色图标、莫奈单色、通知小图标，或“算法补全”把平面图拆成前后景。
- 通知图标只替换状态栏、锁屏、AOD 的小图标，避开会话头像和媒体封面。
- “刷新图标”可更新桌面图标缓存，保留图标排列、文件夹和小组件，不清除桌面数据。

### 来电拦截

- 按 SIM 物理卡槽识别双卡，每张卡可“拦截全部”或按号码规则过滤，`*` 匹配任意长度，例如 `952*`。
- 陌生号码拦截：不在系统通讯录的来电可拦下；三分钟内同一张卡、同一号码的第二次来电放行，避免快递、外卖回拨被误伤。默认关闭。
- 系统原有拦截、全部拦截和手动号码规则优先级更高，重复放行只豁免“陌生号码”这一条。
- 拦截记录仅存本机，保留最近 200 条，显示 SIM 与原因。
- 不接管默认拨号，紧急呼叫等原生场景保持平台处理。

### 加速度传感器控制（防摇一摇）

- 按应用限制“摇一摇”跳转广告：可设为允许、进入前台前 7 秒限制、始终限制。
- 总开关默认关闭，新安装应用继承默认规则，也可逐应用例外。
- 只处理传感器事件，不修改应用本身。

### 边缘防误触

- 左右边缘可分别启用，宽度 1–48dp、覆盖高度和纵向位置均可调，并提供范围预览。
- 适合横屏游戏、看视频时防止手掌误触；中央另一根手指仍可正常操作。
- 可临时显示真实禁触区，方便调整。
- 锁屏、键盘、系统浮层出现时自动暂停。

### 通知与控制中心

- **横屏双栏**：横屏且宽度足够时，通知与控制中心使用原生分栏，不改 DPI、不强开实验开关。
- **状态栏图标垂直位置**：-32 ~ +32dp 微调时间、电量、信号等图标，对齐摄像头或刘海，不改状态栏高度。
- **信号显示调整**：只调整 5G 信号格的显示分档，让“信号其实不差却只有一格”看着舒服些。仅影响 SystemUI 的显示，不改真实信号、通话、网速或网络策略；无服务、无 SIM、飞行模式等状态保持原样，关闭开关立即恢复。默认关闭。

### 安装与要求

1. 安装 APK。
2. 在 LSPosed 中启用“类原生补全计划”。
3. 勾选三个作用域：`系统框架`、`系统界面`、`Pixel 桌面`。
4. 重启手机，或在 LSPosed 中重启对应应用。

要求：已 root 并安装 LSPosed 的类原生 Android（当前针对 Android 17 / API 37 的已核对接口）。不是 SunOS 等 ROM 的完整移植，不同 ROM 上个别功能可能不可用，此时会自动保留系统原生行为。

### 说明

- 全部功能默认关闭，按需开启。
- 不采集通知正文、验证码、剪贴板、电话号码或账号，不上传数据。
- 模块内置“关于 → 诊断日志”，可主动记录、复现、停止并导出，便于反馈问题；它不是完整系统日志，也不自动上传。
- 这是一个个人维护的适配项目，部分功能仍在真机验收中。遇到问题欢迎带机型、ROM、复现步骤反馈。
