2在模块首页进入“双层图标实验”。先选原始图片，再选双层图标；切换后回桌面查看。

3选“分层校验”，底色变薄荷色，Oi 单独右移。打开 Demo 后返回桌面，再查看模块里的原生动画分层反馈。
