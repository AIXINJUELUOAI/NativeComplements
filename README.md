# 类原生补全计划 · NativeComplements

给类原生 Android 补上一些日常用得上的功能：小窗、弹幕通知、快捷建议、图标适配、来电拦截、防摇一摇、边缘防误触，以及通知与控制中心调整。

使用原生 Android 设置风格，支持系统动态颜色和深色模式。不依赖无障碍服务，不接管默认拨号或桌面，也不需要给普通应用逐个添加作用域。

> 当前源码版本：**0.9.19-signal-test1**（versionCode 96）。这是个人维护的系统适配项目，不是 Flyme 或 SunOS 功能的完整移植，也不保证兼容所有类原生 ROM。

## 安装要求

需要已 root、安装兼容现代 libxposed API 101 的 LSPosed 环境。当前主要针对已核对的 **Android 17 / API 37** 系统接口适配；最低安装版本为 Android 14，但能安装不等于所有功能可用。

1. 安装 APK，在 LSPosed 中启用“类原生补全计划”。
2. 勾选模块既定的三个作用域：**系统框架、系统界面、Pixel 桌面**。
3. 自行重启手机后，进入模块按需开启功能。

作用域对应 `system`、`com.android.systemui`、`com.google.android.apps.nexuslauncher`。其他桌面不代表已适配。升级请使用相同签名的 APK，不要为了升级先卸载，以免丢失设置。

## 功能全览

### 小窗

基于系统 freeform 的真实任务小窗，提供类似 Flyme 的小窗使用体验。

- 从屏幕角落斜向滑动呼出扇形菜单，自选常用应用、应用快捷方式与快捷功能。
- 普通小窗、迷你窗及贴边隐藏；迷你窗双击回全屏，长按调整大小或单独静音。
- 可按设置将通知点击、链接、分享和跨应用跳转交给小窗处理。
- 普通小窗采用固定位置，支持竖屏底部键盘避让与横屏布局。
- 菜单集成 Wi-Fi、免打扰、截屏、录屏、亮度、音量、媒体控制等快捷操作。

不同应用对多窗口、输入和方向变化的兼容性不同，不保证全部场景一致。

### 弹幕通知

把选定应用的通知以滚动弹幕显示，减少对当前操作的打断。

- 逐应用开关，保留最近 100 条本地弹幕记录。
- 键盘、锁屏和相关系统浮层等场景按规则暂停或隐藏。
- **弹幕成功显示并记录历史后，才取消对应原通知**，不是投递前拦截；不保证消除原生通知到达瞬间的横幅，提示音和震动仍由系统处理。

### 快捷建议

按场景提供手电筒、本次常亮、蓝牙连接、验证码、链接口令、地点与屏幕旋转等建议按钮。

- 支持调整按钮大小、位置和显示时长，长按拖至关闭区域可隐藏本次提示。
- 验证码可逐位输入；链接和地图可按设置使用小窗打开。
- 旋转建议沿用系统原生目标方向、点击及撤销逻辑。

部分建议和应用输入框仍需更多实机测试；纯口令仅打开对应应用，不保证直达内容。

### 图标适配

支持导入本地图标包，或使用算法补全图标前后景。

- 逐应用设置彩色图标、莫奈单色图标及通知小图标。
- 支持约定目录结构的 ZIP、文件夹及部分 MTZ 内层图标包。
- 可刷新适配的桌面图标缓存，无需清除桌面数据。

算法处理不保证每个图标都有理想效果。图标适配思路参考了 Opticon 等项目；具体复用资源与授权说明见 [NOTICE.md](<NOTICE.md>)。第三方图标素材不随本项目提供，请自行前往 [完美图标计划](https://github.com/pzcn/Perfect-Icons-Completion-Project) 获取，并遵守其授权要求。

### 来电拦截

按 SIM 卡槽设置全部来电、号码规则及陌生号码拦截，支持 SIM2 跟随 SIM1。

- 号码规则支持 `*` 通配符，例如 `952*`。
- 可开启三分钟重复来电豁免，仅豁免陌生号码规则，不绕过全部拦截、手动规则或系统原有拒绝。
- 拦截记录保留最近 200 条，不接管默认拨号角色。
- 陌生号码判断需要通讯录权限；权限不足或查询失败时，该规则保守放行。

**已知反馈：**有设备在开启来电拦截、智能 5G 和 Wi-Fi 的条件下出现 SIM 服务反复变化。日志确认智能 5G 策略参与循环；关闭智能 5G 后再切换飞行模式，用户反馈恢复稳定，但尚未证明是模块与智能 5G 的直接冲突，也未完全排除间接影响。若遇到类似问题，建议先关闭相关功能并反馈；切换飞行模式会暂时中断通信，请自行判断操作时机。

### 加速度传感器控制（防摇一摇）

按应用限制加速度传感器，支持允许、进入前台前 7 秒限制和始终限制。

用于减少部分“摇一摇”广告跳转，**不是通用广告拦截，也不会移除所有开屏广告**；限制传感器可能影响应用正常的体感功能。

### 边缘防误触

左右边缘分别调整禁触宽度、覆盖高度及位置，可预览实际区域。

这是固定区域触摸屏蔽，不是智能手掌识别。实际效果和多指兼容性因场景而异，区域内正常点击也可能被屏蔽，建议按需尝试。

### 通知与控制中心

- **横屏双栏**：在已适配的原生面板上调整通知与控制中心横屏布局，不改 DPI。
- **状态栏位置**：在 −32～+32 dp 范围内调整图标垂直位置，不改变状态栏高度或刘海参数。
- **信号显示调整**：按指定分档调整适用的 5G 信号格，**只改变显示，不增强信号，不提高网速，也不修改网络策略**。

## 隐私与反馈

通知、短信、剪贴板及通讯录相关能力仅用于用户开启的对应功能，在本机处理，不上传相关内容。弹幕历史与拦截记录会在本机保存，可在模块内清空；这不等于“完全不读取或存储通知内容”。

“关于 → 诊断日志”支持主动开始记录、复现、停止并导出有限的模块事件，不是完整系统日志，也不会自动上传。反馈时请说明机型、ROM／Android 版本、模块版本和复现步骤，公开日志前注意检查个人信息。

## 开发与构建

单 app Gradle 模块，Kotlin／Java + Jetpack Compose Material 3。需要 JDK 17+、Android SDK `android-37.0`、Gradle Wrapper 8.14.4。源码命名空间保留 `dev.local.sunwindowdemo`，应用 ID 为 `dev.nativecomplements.module`。

```powershell
.\gradlew.bat --no-daemon --console=plain :app:assembleRelease
python -X utf8 tests/verify_runtime.py
python -X utf8 tests/verify_target.py
python -X utf8 tests/verify_stacked_signal.py
python -X utf8 tests/package_release.py
```

归档目标检查依赖本地系统文件，不随源码发布；缺少归档时不代表检查已通过。打包脚本沿用本地升级签名，校验身份与作用域，仅输出 APK，不安装或操作设备；签名不提交 Git，新开发环境需自行配置。APK 不随源码仓库保存。

管理界面按功能组织，小窗运行代码保留 Demo8.2 包路径；不可变原始基线及变更登记用于回归检查，不能当作临时文件清理。开发约定见 [AGENTS.md](<AGENTS.md>)，小窗实机检查要点见 [DEVICE_ACCEPTANCE.md](<DEVICE_ACCEPTANCE.md>)。
