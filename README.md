# NativeComplements

类原生 Android 功能补全模块。当前版本为 `0.4.1`（versionCode 41），包含小窗、电话拦截、边缘防误触与建议。

设置界面采用 Compose Material 3 / Material 3 Expressive、系统动态颜色和深色模式。首页按功能独立跳转，功能可用后再加入入口。

## 当前小窗实现

- 基于原生 freeform 的默认小窗、mini、小窗与全屏切换，以及关联任务的独立小窗和返回接续。
- 可见 mini 的生命周期与前台输入焦点分开处理；长按菜单提供本应用静音和 mini 大小切换，按钮与图标复用 SunOS 资源。
- 保留应用方向、系统栏取色、最近任务恢复、锁屏后的窗口状态和固定浅色操作条。
- 旋转前先隐藏小窗，原生转场结束且位置稳定后淡入；保留 mini 大小、贴边与静音状态，超时释放旋转遮罩。mini 每次物理旋转后回到可用区域右上角；前台应用切换时保留稳态 mini，原生转场结束事务接回小窗缩放、位置与圆角。
- 普通小窗不可自由移动：竖屏固定现有默认位置，横屏固定居左，包括 mini 展开和关联小程序。默认单击空白处关闭，可在“窗口与多任务”开启双击关闭。竖屏底部固定键盘弹出时整体上移，键盘收起后复位；横屏和悬浮键盘不避让。
- mini 拖动关闭目标对齐系统气泡的底部圆环，靠近时真实内容缩小、变淡并吸向圆心，拉出后平滑恢复；进入圆环时触发一次触感反馈，移出后重新进入可再次提示；取消手势不关闭。
- mini 可跟手拖出物理屏幕，约三分之一宽度越界时轻震，松手隐藏为白条；白条距可用屏幕边缘 12dp，触摸区 48×104dp，优先避让返回手势。点击白条恢复 mini，向屏幕内拖动时实时带出内容；长按轻震后可移动白条位置或拖到另一侧，取消手势复原；隐藏保留原应用生命周期、大小与静音状态。
- SystemUI 承载操作层，system_server 管理任务；不依赖无障碍，不要求为普通应用逐个勾选 LSPosed 作用域。

- 流媒体应用基于原生 freeform 身份拒绝横屏的问题仍未解决；本版没有恢复曾造成布局异常的 fullscreen 配置伪装。
- 普通菜单启动直接在最终小窗位置淡入，不经过全屏缩放。普通与 mini 的形态切换、全屏端点和逻辑画布重布局继续用应用图标与底色遮罩承接，收到匹配配置的新绘制后淡出，超时撤除。旋转保留隐藏后淡入。这些动画仍需真机验收。
- 扇区的菜单入口使用横向三个点并固定最下面，应用图标没有额外底圈或轮廓，选中只放大；设置可选择显示快捷库的前 1–5 项（最多 5 个应用／快捷功能加 1 个三点菜单），默认 4 项加列表入口。快捷库与扇区数量分开保存，最多 512 项并校验跨进程数据容量。
- 应用面板顶部直接显示四列多行常用图标，不加分区标题和图标底色；与下方应用共用图标尺寸、文字样式和列宽，以分割线隔开。菜单复用默认竖向应用小窗的尺寸和位置算法，竖屏居中、横屏靠左，背景不压暗，点击空白关闭。顶部“更多应用”和“管理”使用相同字号、字重、颜色与垂直对齐，无常驻按钮底色；管理支持加减和长按拖动排序，点击完成保存后仍停留在面板。下方按独立字母标题和四列应用行分组，右侧 A–Z 在向下浏览、分割线滚出后显示，回到顶部隐藏，中文按拼音归组。“应用／快捷功能”仅管理时显示。常用区、分割线与分组列表共用一个滚动容器；四列等分、紧凑行距、名称单行省略。截图时保留菜单与管理状态，暂停菜单触摸让截图工具栏优先处理。
- 快捷功能来自系统 LauncherApps，进程内缓存随应用包或快捷功能变更失效，过期查询结果不覆盖新缓存；临时读取或权限失败不缓存。按当前宿主权限与实际可用项显示，不新增桌面或最近任务入口。

这是一套针对已检查的 Android 17 / API 37 私有接口实现的 LSPosed 适配，并非 SunOS ROM 模式的完整移植。构建、主机检查与真机反馈分别记录，见 [VERIFICATION.md](VERIFICATION.md)。

## 建议

- 独立总开关与分类开关，默认总开关关闭；运行于现有 SystemUI/system 作用域，不增加普通应用作用域或无障碍。
- 圆形按钮使用桌面应用图标或操作图标，跟随主题、避让手势条与键盘。点击触发系统轻震。应用／链接／地图成功跳转后消失；验证码开始输入后隐藏，失败时可重试。手电筒操作后保留 5 秒供反向切换，每次点击重新计时。
- CameraManager 真实手电筒状态与 AudioDeviceCallback 蓝牙音频设备连接事件；蓝牙目标从任意可启动应用单选，打开后本次连接不再提示。
- 新短信经 RECEIVE_SMS 运行时权限接收，不读取短信历史；剪贴板识别验证码、十款常用应用链接／口令、地址与地点。仅做本地有界识别，短暂保存在内存中，不记录内容／验证码。
- 验证码默认逐位 100ms，可调 50–500ms，保留前导零。系统侧向用户当前选中的应用窗口发送数字按键，逐次检查窗口对象、UID、键盘、锁屏状态；切换窗口停止。自绘输入框兼容性仍需真机确认。
- 隐藏验证码通知单独开关：仅默认短信应用的非合并、非摘要通知，内容与新收到短信全文一致、且验证码按钮已真正绘制时才取消该条通知；保留 60 秒显示凭据，处理输入完成后才迟到的对应通知。剪贴板候选不触发通知隐藏；不确定时保留原通知，短信接收和保存不变。
- 链接规则覆盖淘宝、京东、拼多多、抖音、快手、哔哩哔哩、小红书、知乎、微博、美团；完整链接交原应用处理，纯口令仅启动应用并保留剪贴板，不声称已经直达商品。地图地址交 geo 搜索，多地图点击选择，地图分享链接保留原 URL。
- 小窗跳转保留整个显式 Intent，以一次性 PendingIntent 复用现有真实启动任务接管链；不退化为仅打开包名首页。关闭此项时全屏打开。手电筒／验证码／常亮不受此项影响。
- 息屏前 DIM 状态下的真实触摸唤亮会提供 15 秒“本次常亮”建议。点击后按钮立即消失，仅持有临时 SCREEN_BRIGHT_WAKE_LOCK，不改息屏时长；下次用户熄屏、锁屏、关闭功能或宿主退出即释放。观察失败仅关闭此建议，不影响系统电源流程。
- 通知、输入和 DIM 观察均独立预检接口并隔离失败；APK 与主机检查不代表真机效果通过。

## 边缘防误触

- 首页独立入口，默认关闭。左右可单独启用并调整 1–48dp 宽度、覆盖高度和纵向位置，提供范围预览。新增默认关闭的“显示实际禁触区”，在现有触摸窄窗内按真实尺寸着色，跟随控件避让和暂停规则。
- 透明窄窗消费边缘触点，通过 split touch 保留中央另一触点的路由；实际多指效果待真机确认。固定区域内正常点击也会被屏蔽，不自动识别手掌。
- 独立设置与 UID 检查的只读 Provider，不跟随小窗开关。锁屏、键盘、系统浮层出现时暂停，避让状态栏、导航区和小窗控件热区。
- 不增加无障碍或普通应用作用域。边缘触摸屏蔽与系统返回 InputMonitor 的准入拦截分开处理。

## 电话拦截

- 首页独立设置页，按 SIM 物理卡槽识别双卡；每张卡可拦截全部来电或按号码规则过滤，保持 SIM 数据连接。
- SIM2 可实时跟随 SIM1，关闭跟随后恢复 SIM2 自己的配置。所有拦截选项默认关闭。
- `*` 匹配任意长度，连续星号合并：`952**` 与 `952*` 均匹配 952 开头的号码。未知号码适用单卡全拦，但不匹配号码规则。
- 拦截记录仅存本机，保留最近 200 条并显示 SIM 和原因。应用的电话权限用于显示双卡名称与状态。
- 系统 Hook 在真实来电的 PhoneAccount → SubscriptionInfo → 卡槽链路上判定，通过 Telecom 原有过滤结果执行挂断与通话日志，不占用默认拨号或来电识别应用角色。紧急回拨等原生紧急场景维持平台处理。
- 本轮接口依据设备 Android 17 的 `service-telecom.jar` 核对，运行于现有 `system` 作用域，无新增普通应用作用域。设置页显示后端最近运行时间；实际来电效果仍需真机验收。

SIM2 服务闪动的现场日志已采集，出现 IMS 注册超时及同一波断链中的无效数据承载响应，关闭拦截后仍持续。采样开始时故障已经存在，日志中也未见实际拦截命中，尚未确定最初触发原因。preview6 保留平台已经阻断或忽略的原始来电结果，避免模块覆盖其原因和处理方式；设置页的配置／心跳刷新不再重复读取 SIM 列表，仅在订阅变化、权限变化或页面恢复时更新 SIM 信息。新增仅在配置变化时输出的开关、规则数量和时间诊断，并展开异常根类型与栈位置，不记录号码或异常原始消息。这些调整不等于 SIM2 闪动已修复；本版未修改 radio、SIM 或数据连接逻辑。

## 环境与构建

- JDK 17+、Android SDK `android-37.0`，Gradle Wrapper 8.14.4。
- SDK 路径通过 `ANDROID_HOME` 或本地 `local.properties` 配置。
- 覆盖升级沿用本机 `.local/demo.keystore`；该文件不进入 Git，新的工作目录需要在本地配置原签名。

Windows 下执行：

```powershell
.\gradlew.bat --no-daemon --console=plain :app:assembleRelease
```

构建、检查包身份和签名并交付 APK：

```powershell
python tests/package_release.py
```

产物位于 `deliverables/NativeComplements-<version>.apk`。脚本只生成 APK，不生成源码 ZIP、备份或验收报告，不安装应用、不操作设备。

## LSPosed 作用域

固定三个作用域：

- `system`
- `com.android.systemui`
- `com.google.android.apps.nexuslauncher`

包名保持 `dev.local.sunwindowdemo`，宿主协议为 16。安装和重启由用户自行安排。

## 项目结构

- `app/src/main/java/dev/local/sunwindowdemo/home`、`navigation`、`core/ui`：首页、导航和共用界面。
- `features/floatingwindow/config`、`features/floatingwindow/ui`：小窗配置与设置页。
- `features/callblocking`：电话设置、规则、记录、受 UID 限制的 Provider 与独立系统 Telecom Hook。
- `features/floatingwindow/legacy`：当前系统 Hook、任务管理、窗口呈现和输入处理。
- `tests`：主机检查、归档接口签名和打包工具。
- `baseline`：不可变 Demo8.2 来源、摘要和历史构建证据。

`python tests/verify_runtime.py` 检查 Demo8.2 来源、变更登记及主机规则；`python tests/verify_target.py` 检查归档目标的一部分接口签名，后者不代表当前设备完整兼容性。

## 开发约定

以 `main` 集成，已交付版本使用 tag 固定。并行功能各用独立分支和 worktree；系统 Hook 入口、共用配置、首页导航与版本号统一集成。运行代码相对 Demo8.2 的变更原因记入 `tests/runtime-changes.json`。

日志、构建缓存、设备采集、签名和交付文件不提交；源码通过 Git 版本管理，不创建逐轮目录副本。
